모든 단계에 우선하는 안전 게이트

문서 확인

CarUxRestrictions가 최종 기준입니다. 차량의 주차 상태와 플랫폼 UX 허용을 모두 확인한 뒤 세션을 시작합니다.

초기·신호 끊김 → 잠금알 수 없는 상태를 허용으로 해석하지 않습니다.
제한 활성 → 전부 중단세션·오디오·화면 상호작용을 멈추고 게임·참여 UI를 숨깁니다.
신호 대기 ≠ 주차(P)속도 0만으로 시작하거나 자동 재개하지 않습니다.

주차 확인 후에도 사용자의 명시 재개가 필요합니다. 주행용 가족 게임 승인을 전제하지 않습니다.

위에서 아래로 진행 · 안전 상태 변화는 어느 단계에서든 우선 처리

  1. 1

    주차 확인 · 15분 시작

    문서 확인

  2. 2

    각자의 선호 · 금지곡

    설계안

    동승자가 선호 시대·분위기·금지곡을 선택합니다. 이름이나 생년월일 없이도 참여합니다.

  3. 3

    자체 곡 메타데이터 · 권리 확보 목록

    설계안

    장르·발매 시기·길이·참여 방식을 정리합니다. 확보한 음원·가사 범위에서만 후보를 만듭니다.

  4. 4

    별도 LLM → 세대별 세트리스트

    설계안

    후보 곡 ID와 시간 예산을 받아 곡 순서와 진행 멘트를 제안합니다. 가사는 생성하지 않습니다.

  5. 5

    세트리스트 검증

    설계안

    곡 ID·금지곡·총 재생 길이·사용 권리를 규칙으로 확인합니다. 검증을 통과한 목록만 재생합니다.

  6. 6

    로컬 음원 · 가사 플레이어

    설계안

    허용된 파일로 재생하고 짧은 진행 멘트를 붙입니다. 네트워크 연결 없이 기본 세션이 동작합니다.

  7. 7

    감상 · 부르기 · 듀엣

    설계안

    참여자가 모드를 고릅니다. 원음 녹음·보컬 점수화는 MVP의 필수 기능으로 가정하지 않습니다.

Gleo 입력 어댑터

승인 필요

App Schema 검토 승인 후 연결합니다. 아래는 앱이 정의할 명령 3개이며 플랫폼 API 이름이 아닙니다.

  1. 세트리스트 시작하기
  2. 다음 곡으로 넘어가기
  3. 앙코르 끝내기

미승인 대체: 터치 또는 모바일 웹 입력을 같은 세션 로직으로 전달합니다.

현재 문서: actionCalls 최대 3개. Gleo가 앱 기능을 호출하며 앱이 결과를 반환합니다.

Gleo ≠ 앱의 생성 AI

곡의 선택·배치·짧은 진행 멘트를 제안합니다. 가사·음원을 만들지 않으며 권리를 판단하지 않습니다.

별도 LLM 백엔드는 앱의 설계안입니다. Gleo의 범용 생성 API 공개를 가정하지 않습니다.

네트워크 단절

설계안

로컬의 권리 확보 음원·가사와 고정 세트리스트를 사용합니다. 곡이 없으면 재생을 건너뜁니다.

시연에서 구분할 것

모의

데모 음원은 사용 허락한 샘플로 표시합니다. 상용곡 스트리밍·마이크 믹싱 지원을 가정하지 않습니다.

경험의 초점

핵심 차별점: 곡 검색을 넘어 가족·세대별 취향을 합의하고 참여 순서를 구성합니다.

오디오 포커스 상실 → 재생 중단

전화·안전 안내·Gleo 등으로 포커스를 잃으면 즉시 멈춥니다. 포커스 회복만으로 자동 재생하지 않고 안전 게이트를 다시 확인합니다.

지원 확인과 앱 권한 승인

문서 존재는 계정 권한·차종 지원·실차 배포 보장이 아닙니다. TTS/STT·위치·차량 제어는 실제 제공 상태를 확인하고 미지원 기능은 대체 경로로 전환합니다.

문서 확인공식 문서의 인터페이스·정책설계안이 앱의 제안 아키텍처승인 필요권한·스키마·실제 제공 상태 확인모의시연용 데이터·대체 입력
