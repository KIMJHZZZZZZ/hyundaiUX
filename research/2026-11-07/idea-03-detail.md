## ⑤ 상세 시나리오: 세 대의 차가 만드는 하나의 여행

‘같이길’은 이미 함께 여행하기로 한 지인 2~4대가 만드는 AI 여행룸이다. 위치 확인을 주된 즐길거리로 삼지 않고, 각 차에서 나온 짧은 이야기와 선택을 휴게소의 공동 챕터와 도착 후 오디오 기록으로 엮는다. MVP의 콘텐츠 입력·선택·재생은 모두 해당 차량의 주차가 확인된 때에만 가능하다. 주행 중에는 세션을 저장하고 화면과 콘텐츠 조작을 잠근다. 동승자가 있다는 이유만으로 전면 화면이나 음성 게임의 주행 사용을 허용하지 않는다.

친구 여섯 명이 차량 세 대로 같은 캠핑장에 간다. 출발지는 다르며, 쉬거나 도착했을 때 각 차의 이야기를 모은다. 아래 7단계는 약 35분으로 압축한 시연이다. 이동 시간과 경로는 실제 교통 예측이 아닌 모의 데이터임을 표시한다.

**1. 출발 전, 오늘의 여행룸 만들기 — 0~3분.** A차가 주차된 상태에서 ‘이번 여행 만들기’를 누르고 여행명, 목적지, 예정된 휴식 장소를 입력한다. 초대 링크나 QR을 친구들에게 공유한다. 초대받은 사람은 여행명과 방장을 확인하고 참여한다. 각 차량은 별명만 정하고, 공동 기록에 이름·음성·사진 중 무엇을 남길지 선택한다. 정확한 위치 공개와 콘텐츠 공개는 별도 동의이며, 위치 없이 공동 기록만 참여할 수도 있다. 링크에 접속했다고 즉시 위치를 전송하지 않는다.

**2. 주차 상태에서 프롤로그 만들기 — 3~6분.** 세 차량에 ‘오늘 기대하는 순간 하나’를 묻는다. A차는 “불멍”, B차는 “쉬기”, C차는 “다 같이 저녁 만들기”를 고른다. 짧은 음성도 가능하다. AI는 이 답으로 30초 이내의 여행 소개를 작성하며 성격이나 감정을 추정하지 않는다. 각 차는 제출 내용과 공개 범위를 확인하고, 주차 중 프롤로그를 듣는다. 건너뛰어도 다음 단계가 막히지 않는다.

**3. 한 대라도 출발하면 차량별로 일시중단 — 6~18분.** A차가 먼저 출발하면 A차의 입력·재생·알림을 멈추고 현재 챕터를 저장한다. 아직 주차된 B·C차는 각자 준비를 마칠 수 있다. 다른 차량이 주차되어 있다는 사실로 내 차량의 잠금을 풀지 않는다. 움직이는 동안 답을 재촉하거나 다른 차의 새 메시지를 읽어주지 않는다. 서버는 마지막으로 승인된 참여 상태와 챕터 진행만 보관한다. 모의 경로 화면은 개발자 시연용이며 실제 차량의 운전자 화면에는 노출하지 않는다. 차량 상태를 읽지 못하면 주행인지 추정하지 않고 잠금 상태를 유지한다.

**4. 휴게소 도착 순서가 달라도 기다림을 콘텐츠로 바꾸기 — 18~22분.** A차가 먼저 도착해 주차하면 ‘첫 번째 쉼표’가 열린다. “출발 전 예상과 달랐던 점”, “다음 구간에서 기대하는 일” 중 하나를 선택해 10초 내외의 조각을 남긴다. 아직 이동 중인 B차에 응답 요청을 보내지 않는다. C차가 휴게소에 들르지 않기로 했다면 챕터를 건너뛸 수 있다. 모든 차가 같은 시각에 모여야 한다는 압박 대신, 이번 챕터에 참여할 차만 선택한다. 늦은 차에 속도를 내라고 암시하는 순위·거리 경쟁·도착 배지는 없다.

**5. 참여 차량이 각각 주차한 뒤 공동 챕터 — 22~27분.** A·B차가 참여를 확인하면 서버가 제출된 조각을 하나의 챕터로 편집한다. 화면에는 “두 차의 이야기로 구성, C차는 다음 쉼표에서 합류”처럼 참여 범위를 분명히 표시한다. AI는 서로 다른 답을 이어 60~90초 분량의 가벼운 오디오를 만든다. ‘누가 가장 먼저 도착했나’ 대신 ‘오늘 여행의 제목을 무엇으로 할까’ 같은 주차 중 선택을 한 번 제공한다. 생성된 제목은 참가자가 수정할 수 있다. 공개에 동의하지 않은 발언은 원문·요약·오디오 어디에도 넣지 않는다. 한 대가 출발하면 그 차만 즉시 재생을 중단하고 나머지는 주차 상태에서 마칠 수 있다.

**6. 다음 이동 구간 — 27~31분의 압축 시연.** 챕터 결과와 재생 위치를 저장한 뒤 각 차량을 다시 잠근다. 네트워크가 끊겨도 확정된 기록은 로컬에 남으며 재연결 시 중복 제출하지 않는다. 휴게소 변경이나 새 초대는 주차 후 처리한다. 차량을 따라잡는 경로나 새 집결 장소를 자동 지정하지 않는다.

**7. 목적지 주차 후, 함께 완성한 여행 기록 — 31~35분.** 각 차가 목적지에 주차하면 오늘의 마지막 한 줄을 남긴다. 서버는 승인된 조각만 모아 짧은 오디오 여행기와 챕터 카드로 완성한다. 마지막 도착을 기다리지 않고 개인 미리보기를 제공하되, 다른 사람이 아직 확정하지 않은 내용은 넣지 않는다. 참가자는 저장·삭제·그룹 공유를 선택하며, 외부 공유는 별도로 확인한다. 여행 종료 시 위치 공유는 자동으로 끝난다. 결과물에는 정확한 집 주소·전체 이동 궤적·차량 속도를 남기지 않는다. 즐거움의 결과는 ‘낯선 사람 한 명을 찾았다’가 아니라 ‘각 차의 이야기가 우리 여행 한 편이 됐다’이다.

오픈 매칭은 이번 MVP에서 제외한다. 실시간 후보는 전체 가입자 수가 아니라 ‘지금 여행 중인 사람 × 같은 방향·시간 × 비슷한 목적 × 참여 의향 × 신뢰 조건’의 교집합이다. 이를 만족하는 한국 사용자 규모를 입증할 대표 조사나 실적은 이번 조사에서 확보하지 못했다. 집과 이동 경로 노출, 낯선 사람의 접근, 무응답과 불쾌한 콘텐츠 처리까지 맡아야 하는 반면, 카풀의 비용 절감 유인은 없다. 지인 초대는 초기 밀도와 신뢰 문제를 줄이지만, 공동 오디오가 메신저보다 좋은지는 여전히 사용 실험으로 확인해야 한다.

## ⑦ 구현 파이프라인: 동의부터 공동 기록까지

**입력과 초대.** 서버는 여행룸, 차량별 참가자, 초대 만료시간, 동의 버전을 보관한다. 초대 토큰은 만료·취소할 수 있고, 참여와 공개에 동의한 사람만 룸 자료를 받는다. 목적지·휴식 장소는 수동 선택부터 시작하며 장소 ID나 확인된 좌표로 정규화한다.

**목적지·경로·시간 필터.** 초대된 사람 안에서 동일 목적지 여부를 확인하고, 경로가 있다면 도로망의 방향과 공통 구간을 비교한다. 가까운 좌표라도 반대 차선·다른 진입도로이면 같은 진행 구간으로 취급하지 않는다. 공통 구간의 예상 통과 시간도 비교하며, 목적지만 같고 출발 시간이 크게 다른 차량은 별도 챕터로 둔다. 경로가 없는 경우 목적지 수동 확인만으로 콘텐츠 룸에 참여시키고 ‘경로 일치 미확인’ 상태를 유지한다. LLM이 경로 중첩이나 ETA를 추정해서 확정하지 않는다.

**차량 데이터의 범위.** 현재 구현 계획에서 FusedLocation은 준비 중으로 분류하며, 위치가 바로 제공된다고 가정하지 않는다. NaviHelper는 문서상 연계 가능성을 검토하되 실제 이벤트·ETA의 제공 범위와 권한은 개발 계정에서 확인해야 한다. 확인 전에는 경로와 이동 시각을 모의 데이터로 제공하고 시연 화면과 발표에서 명시한다. 차량 상태 연동도 SDK 지원·권한 확인과 실제 이벤트 시험을 거쳐야 한다. 테스트 스위치는 개발자용 에뮬레이터에만 두고, 실차 사용자가 임의로 ‘주차 중’을 선택해 잠금을 푸는 대체 기능은 두지 않는다.

**서버 챕터와 동기화.** 룸은 프롤로그·쉼표·도착 기록으로 구성하며, 각 차량은 잠김·참여 가능·제출 완료·건너뜀 상태를 갖는다. 방장의 차량 상태를 전체 룸에 적용하지 않는다. 서버는 챕터 버전과 제출 ID를 관리하고 중복 요청을 무시한다. 모든 차량이 동시에 주차해야만 앱 전체를 사용할 수 있게 만들지 않고, 해당 챕터에 참여를 선택하고 주차가 확인된 차량끼리 진행한다. 다른 차가 주행 중이면 콘텐츠나 응답 요구를 전송하지 않는다. 서버와 상태 동기화가 늦어도 각 차량의 로컬 주행 잠금이 우선한다.

**LLM 편집.** 별도 백엔드가 승인된 원문과 여행명, 챕터 종류를 받아 편집한다. 모델 입력에는 정밀 이동 궤적이나 불필요한 개인정보를 제외한다. 출력은 자유문만 받지 않고 아래처럼 정해진 JSON으로 받는다.

```json
{"chapterId":"rest-01","title":"첫 번째 쉼표","segments":[{"sourceIds":["clip-a1"],"text":"A차는 저녁 식사를 기대하고 있어요."}],"durationTargetSec":60,"requiresPark":true}
```

백엔드는 필수 필드·길이·허용된 sourceIds를 검사한다. 문장에 근거가 없거나 참가자의 미승인 내용을 포함하면 재생하지 않는다. 차량은 검증된 결과를 받아 주차 중에만 화면과 TTS로 제공한다. LLM은 룸 권한 변경, 경로 수정, 위치 공개, 다른 사람 초대, 챕터 강제 참여를 직접 실행하지 않는다. Gleo 연계는 승인 절차가 필요하므로 MVP의 필수 의존성으로 삼지 않는다. 승인 후 연결하더라도 App Schema에 등록하는 actionCalls는 최대 3개이며, 콘텐츠 편집은 별도 LLM 백엔드가 담당한다. 플랫폼 규격과 승인 결과는 구현 직전 재확인한다.

**실패 처리.** 생성 지연이나 JSON 오류 시 ‘A차의 한 줄 / B차의 한 줄’ 고정 템플릿으로 이어간다. 빈 응답은 가짜 발언으로 채우지 않는다. 네트워크가 끊기면 제출물을 로컬에 보관하고 최신 확인 시각을 표시한다. 위치·ETA가 오래되면 현재 값처럼 보여주지 않는다. 차량 상태가 미확인이거나 출발 신호를 받으면 재생과 조작을 즉시 멈춘다. 참가자가 나가거나 동의를 철회하면 이후 생성 입력에서 제외하고, 저장된 공동 기록의 처리 범위도 동의 설정에 따라 반영한다. 여행 종료 시 위치 세션을 닫고, 원시 위치와 저장할 공동 기록의 보존 정책을 따로 적용한다.

## ⑧ MVP·검증·사업·미래

**11월 13일 목표 MVP.** 11월 8~9일에는 두 차량의 초대·동의·주차 잠금·챕터 상태를 연결한다. 10~11일에는 고정 질문 세 개, 짧은 텍스트/음성 조각, LLM JSON 편집, 도착 카드 저장을 구현한다. 12~13일에는 두 대의 에뮬레이터 또는 한 대의 에뮬레이터와 가상 클라이언트로 출발 시각 차이, 한 차량의 이동 중단, 네트워크 단절, 중복 제출, 생성 실패를 시연한다. 이는 목표 일정이며 완료 사실이 아니다. 경로는 모의 데이터, 미승인 Gleo는 제외한다. 실제 차량 위치·내비 연동이 없더라도 공동 콘텐츠와 차량별 상태 처리는 완결된 흐름으로 보여준다.

**검증할 질문.** 최근 1년 이내 2대 이상으로 여행한 그룹에 연락 수단, 휴식 장소 결정 과정, 차가 나뉘어 아쉬웠던 경험을 묻는다. 호감보다 최근 행동을 확인한다. 이후 주차된 환경에서 일반 그룹 채팅과 같이길의 기록 경험을 비교한다. 공동 오디오가 재미없거나 준비가 귀찮으면 콘텐츠 구조를 줄이거나 후보를 재평가한다. 모집 규모와 통과 기준은 사전에 정하되 결과처럼 발표하지 않는다.

**측정 지표.** 활성화는 ‘초대 수락 차량이 2대 이상이며 첫 공동 챕터를 완료한 룸’, 콘텐츠 완성률은 ‘도착 기록 생성 룸 ÷ 활성화 룸’으로 정의한다. 재방문은 여행 서비스 특성을 고려해 ‘후속 다차량 여행 기회가 있었던 그룹 중 다시 사용한 그룹’과 일반 30일 재방문을 구분한다. MAU는 월간 고유 활성 이용자이며 차량 수·룸 수와 혼용하지 않는다. 예상 유입은 ‘제휴 여행 그룹 수 × 링크 노출률 × 수락률 × 활성화율’로 계산하되 모든 입력은 가정임을 표시한다. 예를 들어 제휴처가 있다고 가정해 계산한 결과를 확보된 고객이나 매출로 제시하지 않는다. 안전 관련 검증은 주행 상태에서 입력·재생 0건, 상태 미확인 시 잠금 유지, 다른 차 상태로 잠금 해제 불가를 필수 조건으로 둔다.

**사업화 가설.** 캠핑장·행사 운영자·자동차 동호회가 제공하는 여행 기록 패키지를 시험한다. 기본 기록은 무료, 승인된 사진을 포함한 고품질 오디오·기념 카드 내보내기는 유료 가설로 둔다. 결제 전환과 음성 인식·LLM·TTS·저장 비용, 지원 부담을 함께 측정한다. 정밀 위치 판매를 전제로 삼지 않으며, 한 번의 여행에서 가치를 만드는 상품으로 평가한다.

**미래 확장 순서.** 첫 단계는 지인 초대, 두 번째는 참가자가 명시적으로 선택한 동일 행사·캠핑장 그룹이다. 행사 운영자가 지정한 출발 시간·목적지·휴식 지점으로 후보 밀도를 확보하고, 참여 전에는 대략적인 일정과 관심사만 공개한다. 상호 수락과 신고·차단·운영 대응을 갖춘 뒤에만 새로운 동행 소개를 시험한다. 세 번째로 충분한 이용 밀도와 수요를 확인한 특정 시간·지역에서 제한된 매칭을 검토한다. ‘지금 근처의 모든 낯선 차’로 곧바로 확장하지 않는다. 주행 중 순수 오디오 역시 별도 플랫폼 심사와 안전 평가를 통과한 경우의 후속 기능이며, 이번 MVP의 성공 조건이나 허용 사실로 제시하지 않는다.
