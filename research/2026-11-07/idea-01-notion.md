## ⑤ 상세 시나리오

<b>우리차 라디오</b>는 가족이 돌아가며 자기 이야기를 보태는 15분짜리 차량 라디오다. AI의 역할은 재미있는 말을 계속 생산하는 것이 아니라, 가족의 짧은 발언을 다음 사람에게 연결하고 실제 대화가 시작되면 물러나는 것이다. 핵심 기능은 ① 가족별 한마디를 잇는 진행, ② 함께 고른 소재를 짧은 에피소드로 만드는 이야기, ③ 대화를 방해하지 않는 멈춤·재개 세 가지로 제한한다. 공모전 MVP는 주차 상태에서만 실행한다. 음성 중심이라는 이유로 주행 중 사용이 허용되거나 안전하다고 전제하지 않는다.

대표 사용자는 초등학생 자녀와 보호자가 함께 탄 가족이다. 주말 체험 장소에 일찍 도착했거나 충전하는 동안 15분을 함께 보내는 상황을 가정한다. 이 연령·상황은 초기 검증을 위한 선택이며 시장 전체의 대표 사용자라는 뜻은 아니다. 화면에는 이름 대신 가족이 정한 별칭, 다음 차례, 남은 시간, 큰 일시정지 버튼만 둔다. 저장하지 않는 일회성 세션을 기본으로 하고 가족 기록은 별도 선택으로 남긴다.

| 시간·단계 | 사용자 발화·행동 | 시스템 동작 | 예외와 얻는 가치 |

이 흐름의 성공은 AI 이야기의 길이나 생성 횟수로 판단하지 않는다. 처음에는 무관심했던 가족 구성원이 다른 사람에게 질문했는지, 그 뒤 AI가 적절히 멈췄는지가 더 중요하다. 이야기만 듣고 싶은 날에는 청취 모드를 허용한다. 가족관계를 개선하거나 심리 문제를 해결한다는 효능을 주장하지 않는다.

<b>검증된 문제와 아직 검증되지 않은 서비스 가설을 나눠 읽어야 한다.</b> 아래 자료는 차량에서 가족 대화·놀이·기술 이용이 발생한다는 근거다. 한국 가족이 우리차 라디오를 설치하거나 반복 사용하고 비용을 낸다는 사실까지 증명하지 않는다. 원문을 직접 열어 확인했으며 제조사 보도자료는 해당 기업의 이해관계가 있는 자료로 취급한다.

차별화 후보는 <b>가족의 발언 연결과 AI의 자발적인 퇴장</b>이다. 같은 소재의 기존 오디오북보다 가족끼리 이어 묻는 횟수가 늘고, 일반 AI 진행보다 방해받았다는 느낌이 줄어들어야 가치가 성립한다. 자녀가 말을 싫어하거나 보호자가 휴식을 원하면 ‘좋은 가족 대화’를 강제하지 않는다. 조용히 듣기·건너뛰기·종료가 핵심 사용 흐름에 포함되어야 한다.

## ⑦ 구현 파이프라인

구현은 차량 Android 앱, 별도 LLM 백엔드, 음성 입출력 어댑터로 분리한다. Pleos 공개 범위와 허용된 연결 방식은 공통 기술 별첨을 기준으로 재확인한다. State와 NaviHelper가 공개되어 있어도 해당 기기에서 필요한 데이터·권한을 바로 사용할 수 있다고 가정하지 않는다. Control, FusedLocation, Pleos STT/TTS는 준비 중인 항목으로 취급하고 MVP의 필수 의존성에서 제외한다. 위치·조명·좌석 제어 없이도 첫 경험이 성립해야 한다.

| 발언 버튼 또는 허용된 STT 텍스트 | 길이 제한, 민감정보 제거, 화자 차례 매핑 | 발언을 왜곡하지 않는 한 줄 요약 | 사용자 확인용 문장 | 원문 터치 수정·미사용 선택 |
| 승인 발언·현재 장면·잔여 시간 | 장면 수·질문 수·응답 길이를 제한 | 다음 짧은 장면·연결 질문 생성 | 검증된 JSON의 대사·선택지 | 제한시간 초과 시 준비된 장면으로 진행 |
| 대화 버튼·음성 활동 신호 | 재생 중단과 재개를 로컬 상태로 관리 | 대화를 재촉하지 않음 | 조용한 대기 화면 | 자동 감지가 불안정하면 버튼만 사용 |
| 종료 요청·남은 시간 | 마감 우선, 추가 장면 생성 금지 | 기존 선택을 반영한 짧은 결말 | 제목·결말·선택 저장 | 사전 결말과 즉시 종료 |

백엔드는 예를 들어 <code>scene_id</code>, <code>mode</code>, <code>narration</code>, <code>question</code>, <code>choices</code>, <code>duration_hint_sec</code>를 받는 JSON 스키마를 둔다. <code>mode</code>는 정해진 값만 허용하고 선택지는 최대 두 개, 질문은 한 개, 출력 길이는 정해진 상한을 넘지 않도록 검증한다. LLM이 임의로 새 API 이름이나 차량 명령을 만들어도 실행하지 않는다. 타임아웃·파싱 오류·길이 초과는 앱이 검출하고 허용된 수정 한 번 또는 사전 콘텐츠로 전환한다. 화면 상태와 실제 진행 순서는 앱의 상태 머신이 관리한다.

Gleo는 별도 승인 인터페이스이며 범용 LLM 실행 환경으로 취급하지 않는다. 연동하더라도 정의된 기능 호출에 한정하고 <code>actionCalls</code>는 최대 3개라는 경계를 지킨다. 가족 이야기 생성은 별도 LLM 백엔드에서 수행한다. API 키는 앱에 넣지 않고 서버에서 관리하며, 참가자의 발언을 상품 분석용으로 무기한 저장하지 않는다. 외부 모델 전송 범위는 시작 전에 짧게 설명한다.

11월 13일 시연에서는 터치 입력과 실제 LLM 텍스트 생성을 반드시 구분해 보여준다. 음성이 준비되면 허가된 외부 음성 서비스를 붙이고, 그렇지 않으면 사전 녹음한 진행 오디오와 실제 생성 텍스트를 조합한다. 이때 사전 오디오가 방금 생성된 가족 맞춤 음성인 것처럼 연출하지 않는다. 실제 음성으로 읽을 수 없는 생성 장면은 화면 자막으로 확인하거나, 미리 준비한 오디오 장면 중 사용자가 고르게 한다.

## ⑧ MVP·검증·사업·미래

<b>11월 13일 MVP 완료의 기준</b>은 주차한 2\~3인 가족이 한 번의 세션을 시작하고, 두 개 이상의 발언이 다음 장면에 반영되며, 가족 대화 중 AI를 멈추고, 네트워크 오류가 나도 안전하게 종료하는 것이다. 시연을 위해 음성 화자 분리, 연속 자동 듣기, 장기 가족 기억, 위치 연동, 조명·시트 제어, 자동 영상 제작은 제외한다. 기능 수보다 시작에서 종료까지 한 흐름을 확실히 완성한다.

11월 7\~8일에는 세 가지 소재와 진행 상태, JSON 스키마, 녹음·저장 선택을 확정한다. 9\~10일에는 터치 기반 앱과 실제 LLM 백엔드를 연결하고 실패 대체 경로를 넣는다. 11일에는 주차 상태 이탈·통신 지연·잘못된 JSON·사용자 중도 종료를 확인한다. 12일에는 가능하면 2가구의 사전 사용으로 이해하기 어려운 문구를 고치고, 13일에는 실제 연결 모드와 오프라인 대체 모드를 구분한 시연을 준비한다. 일정상 참가자 확보가 안 되면 내부 시연 결과를 가족 조사처럼 포장하지 않는다.

국내 검증은 초등학생 자녀가 있는 <b>8\~12가구의 탐색 실험</b>으로 계획한다. 수도권·지방, 자녀 연령, 평소 차량 이용 빈도가 한쪽으로만 쏠리지 않도록 모집하되 통계적 대표 표본이라고 부르지 않는다. 각 가구가 두 조건을 경험하는 교차 방식으로 순서를 반씩 바꾼다. A는 같은 길이·소재의 고정 오디오 이야기, B는 발언 연결·대화 멈춤이 있는 우리차 라디오다. 1차 실험에서는 모두 주차 상태이고 운전 과제를 부여하지 않는다.

핵심 지표는 ① AI 질문 직후가 아닌 가족의 자발적 질문·응답이 이어진 구간 수, ② 원하지 않는 AI 끼어들기 횟수, ③ 다음 사용 기회에 보호자와 자녀가 각각 고른 재사용 의향이다. 발화량 자체를 높이려고 설계를 왜곡하지 않도록 참여 강요·피로도·인지된 즐거움을 함께 기록한다. 관찰 기록은 최소화하고 가족 동의 없이 대화 전문을 보관하지 않는다. 7일 내 자연스러운 재사용 기회가 있었는지 확인하되 실제 앱 사용과 설문 의향을 구분한다.

중단 기준도 사전에 둔다. P 해제, 아동·보호자의 중단 요청, 불쾌한 질문, 잘못된 개인 이야기 귀속이 생기면 해당 세션을 즉시 끝낸다. 탐색 결과 절반 이상 가구에서 B의 방해감이 A보다 높거나, 자발적 대화가 늘지 않으면서 준비 부담만 증가하면 자동 진행 방식을 중단하고 소재 카드 중심으로 바꾼다. 이 절반 기준은 통계적 유의성 기준이 아니라 제한된 자원에서 다음 개발을 결정하기 위한 사전 운영 기준이다.

사업 가설은 무료 짧은 세션으로 사용 맥락을 확인한 뒤 여행·기념일용 에피소드 팩 또는 차량 콘텐츠 제휴를 실험하는 것이다. 예를 들어 팩 2,900원과 월 4,900원은 인터뷰에서 비교할 <b>가상의 실험 가격</b>이며 적정 가격이나 매출 전망이 아니다. 시장규모·MAU·유지율은 현시점에 제시할 근거가 없고, 부모 표본 수에 가족 전체를 곱해 시장으로 추정하지 않는다. 비용은 실제 세션의 모델 호출량·음성 변환량·콘텐츠 검수 시간을 기록해 계산한다.

장기적으로는 가족이 동의한 소재만 이어가는 계절별 에피소드, 여러 언어를 쓰는 가족의 차례별 언어 선택, 동승자별 참여 강도 조절을 확장할 수 있다. 차량 기능을 추가하기 전에 “AI가 없어도 대화가 이어지는가”를 확인한다. 가족 사이에 자연스러운 대화가 생겨 AI 사용 시간이 줄어드는 결과도 이 서비스의 성공으로 평가한다.
